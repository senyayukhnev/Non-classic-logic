# Комплекс программ «Нечёткие величины равномерного вида и кластерный анализ»

Вариант: функция принадлежности строится по закону **равномерного распределения**.
Язык: Python 3.10+, зависимости — `numpy`, `matplotlib` (GUI — стандартный `tkinter`).

## 1. Теоретические сведения

### 1.1. Представление нечёткой величины
Плотность равномерного распределения на отрезке [a, b]:
f(x) = 1/(b−a) при a ≤ x ≤ b, иначе 0.

Функция плотности, нормированная к высоте 1 (условие нормальности нечёткого множества), даёт
функцию принадлежности прямоугольного вида:

μ(x) = 1, если a ≤ x ≤ b; μ(x) = 0 иначе.

Нечёткая величина полностью задаётся парой параметров **(a, b), a ≤ b** — обозначаем `U[a; b]`.
Чёткое число c — вырожденный случай `U[c; c]`.

Характеристики:
* центр тяжести (дефаззификация) = (a+b)/2 — совпадает с мат. ожиданием распределения;
* ширина (носитель) = b − a;
* дисперсия исходного распределения = (b−a)²/12.

### 1.2. Арифметические операции
Операции определяются принципом обобщения Заде: μ_{A∗B}(z) = sup_{z = x∗y} min(μ_A(x), μ_B(y)).
Через α-срезы: [A∗B]_α = [A]_α ∗ [B]_α (интервальная арифметика). У прямоугольной величины все
α-срезы одинаковы и равны [a, b], поэтому результат — снова величина вида `U`:

| Операция | Результат |
|---|---|
| A + B | U[a₁+a₂; b₁+b₂] |
| A − B | U[a₁−b₂; b₁−a₂] |
| A × B | U[min P; max P], P = {a₁a₂, a₁b₂, b₁a₂, b₁b₂} |
| A ÷ B | A × U[1/b₂; 1/a₂], определено только если 0 ∉ [a₂; b₂] |
| −A | U[−b; −a] |
| A ∩ B (min) | U[max(a₁,a₂); min(b₁,b₂)] или ∅ |
| оболочка A ∪ B | U[min(a₁,a₂); max(b₁,b₂)] |

Пример: U[2;5] + U[1;3] = U[3;8]; U[2;5] − U[1;3] = U[−1;4]; U[2;5] ÷ U[1;3] = U[0.667;5].

Замечание: A − A ≠ 0 (получается U[a−b; b−a]) — это свойство интервальной/нечёткой арифметики.

### 1.3. Сравнение величин
* **По центру тяжести** (основное, используется операторами `<, >, <=, >=`): A > B, если
  (a₁+b₁)/2 > (a₂+b₂)/2; при равенстве центров меньшей считается более узкая величина.
* **Степень предпочтения** P(A > B) — вероятность того, что X~U[a₁;b₁] больше независимой
  Y~U[a₂;b₂]: P = (1/(b₁−a₁))·∫ F_Y(x) dx по [a₁; b₁]. Учитывает «вероятностную» природу варианта.
* **Возможность** Poss(A ≥ B) = 1, если b₁ ≥ a₂; **необходимость** Nec(A ≥ B) = 1, если a₁ ≥ b₂.
* **Сходство Жаккара** |A∩B| / |A∪B| ∈ [0; 1].
* **Расстояние** d(A,B) = √(∫₀¹ ((a₁(α)−a₂(α))² + (b₁(α)−b₂(α))²)/2 dα) = √(((a₁−a₂)² + (b₁−b₂)²)/2).

### 1.4. Кластерный анализ
Каждая величина — точка (a, b) с метрикой d из п. 1.3.

1. **На заданное число кластеров k — нечёткие c-средние (FCM, Бездек).**
   Минимизируется J = Σᵢ Σⱼ uᵢⱼᵐ d²(xᵢ, vⱼ), где uᵢⱼ — степень принадлежности величины i кластеру j
   (Σⱼ uᵢⱼ = 1), m > 1 — фаззификатор. Итерации:
   vⱼ = Σᵢ uᵢⱼᵐ xᵢ / Σᵢ uᵢⱼᵐ; uᵢⱼ = 1 / Σₗ (d(xᵢ,vⱼ)/d(xᵢ,vₗ))^{2/(m−1)} — до max|ΔU| < ε.
   Прототип кластера vⱼ — сам является нечёткой величиной U[a; b]. Итоговое (чёткое) разбиение —
   по максимуму uᵢⱼ.
2. **По критерию — порог сходства α.** Строится нечёткое отношение сходства
   R(i,j) = 1 − d(i,j)/d_max (рефлексивно, симметрично). Его max-min транзитивное замыкание —
   отношение нечёткой эквивалентности; α-срез замыкания разбивает множество на классы.
   α-срез замыкания совпадает с компонентами связности графа с рёбрами R(i,j) ≥ α, это и реализовано
   (O(n²)). Чем больше α, тем больше кластеров (α=0 → 1 кластер, α=1 → каждая различная величина отдельно).
3. **По критерию качества — индекс Се–Бени (авто-выбор k).**
   XB = Σᵢⱼ uᵢⱼᵐ d²(xᵢ,vⱼ) / (n · min_{j≠l} d²(vⱼ,vₗ)). FCM запускается для k = 2..k_max,
   выбирается k с минимальным XB.

## 2. Состав комплекса

```
fuzzy_uniform/          независимая библиотека (не зависит от GUI)
  number.py             класс UniformFuzzyNumber, операции, сравнение, расстояние
  collection.py         генерация набора, сохранение/загрузка CSV
  clustering.py         FCM, индекс Се–Бени, auto_fcm, кластеризация по порогу α
  __init__.py           публичный API, setup_log() — журнал в файл
app_gui.py              графический интерфейс (tkinter + matplotlib)
example_external.py     пример использования библиотеки внешней программой
tests/                  модульные тесты
```

### 2.1. API библиотеки

| Объект | Назначение |
|---|---|
| `UniformFuzzyNumber(a, b=None)` | создание величины (`b=None` → чёткое число); `+ − * /`, унарный `−`, сравнения, `mu(x)`, `alpha_cut(α)`, `center`, `width`, `variance`, `intersection()`, `hull()` |
| `compare(x, y)` | −1 / 0 / 1 по центру тяжести |
| `prob_greater(x, y)`, `possibility_ge`, `necessity_ge`, `jaccard`, `distance` | меры сравнения (п. 1.3) |
| `generate(n, groups, center_range, width_range, spread, seed)` | набор из n величин; `groups` — число «скрытых» групп (0 — без структуры) |
| `save_csv(numbers, path, labels=None)`, `load_csv(path)` | файл CSV, разделитель `;`, столбцы `a;b[;cluster]` |
| `fcm(numbers, k, m=2, eps, max_iter, seed)` | → `ClusterResult` |
| `auto_fcm(numbers, k_min, k_max, m, seed)` | → `ClusterResult` с `scores` = {k: XB} |
| `similarity_clusters(numbers, alpha)` | → `ClusterResult` |
| `xie_beni(numbers, result, m)` | значение индекса |
| `ClusterResult` | `labels`, `centers`, `membership`, `iterations`, `scores`, `k`, `sizes()` |
| `setup_log(path)` | включить журнал библиотеки в файл |

Журнал ведётся стандартным `logging` под именем `fuzzy_uniform`; внешняя программа может
подключить свои обработчики.

Пример:
```python
import fuzzy_uniform as fu
A, B = fu.UniformFuzzyNumber(2, 5), fu.UniformFuzzyNumber(1, 3)
print(A + B, A / B, A > B, fu.prob_greater(A, B))
data = fu.generate(200, groups=4, seed=1)
res = fu.fcm(data, k=4)
print(res.sizes(), res.centers)
```

## 3. Порядок использования

Установка зависимостей и запуск (cmd, из папки проекта):
```
pip install -r requirements.txt
python app_gui.py
```

Вкладки окна:
1. **Операции** — ввести a, b для A и B, нажать операцию (+, −, ×, ÷, ∩, оболочка) или
   «Сравнить». Результат — текстом и графиком функций принадлежности.
2. **Набор величин** — параметры генерации (n = 100–300, число групп, диапазоны центров и ширин,
   seed) → «Сгенерировать». Таблица и график набора; загрузка/сохранение CSV (с номерами кластеров).
3. **Кластеризация** — выбрать метод (FCM с заданным k / авто по Се–Бени / порог α), параметры →
   «Выполнить». Выводятся число кластеров, размеры, прототипы, индекс XB; графики: величины,
   раскрашенные по кластерам, и плоскость «центр–ширина» с прототипами.

Внизу окна — журнал действий; он же пишется в файл `fuzzy.log`.

Тесты: `python -m unittest -v`; пример внешней программы: `python example_external.py`.
